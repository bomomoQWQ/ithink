## 实际进程场景

- 运行中热替换，后续请求落到新实例。
- 协议版本错误、ready 后退出、未确认激活，旧实例继续可用。
- 替换旧实例时，其未结束请求明确返回插件不可用。
- 后台慢调用和新插件握手时，其他请求仍可处理。
- 后端原生 JSON 错误保留；内核超时与原生错误分开。
- 后端进程崩溃只结束相关调用，不结束内核。
- 缺少依赖、卸载仍被依赖插件、成环替换被拒绝。
- 主代理通过公开 API 启动模板工作代理、赋予上下文、接收结果并卸载它。
- 订阅者直接接收有序消息。
- 插件停止读取输入、内核写管道阻塞时，卸载不无限等待。
- Windows 卸载插件后，继承通信句柄的后代进程也退出。

## Web 与浏览器验证

- 独立深色 Agent 工作界面、会话侧栏、聊天/输入/停止、模型设置；不是原来的任务调试大表格。
- 真实链路：浏览器 → 本机 HTTP API → 内核 → 循环插件 → 独立模型适配进程 → 本机兼容 API；不是浏览器伪造回答。模型工具调用、加法结果回注、多轮上下文和会话隔离通过。
- 配置/真实连接测试、Authorization、32 token 预算、空 key 保留与清除、origin 更换不转发旧 key、公开状态和磁盘不含密钥、错误/重定向脱敏、原子保存及坏文件恢复通过。
- 设置项覆盖 DeepSeek 当前模型与参数：`thinking`/`reasoning_effort`、`top_p`、可选 `max_tokens`、`stop`、`response_format`、`safety_check`；旧设置文件缺少新字段时回落默认值，mock 请求体断言了这些字段与 `reasoning_content` 的回传规则。
- 流式链路实测：本地 mock SSE 服务依次返回 reasoning/content 增量，模型插件经内核临时事件发布，Web `/api/stream` 收到 4 个增量事件；拼接内容为“实时流式回答。完成”、推理为“先想一想。”，任务最终 completed，mock 收到 `stream:true`。增量事件不写 journal；离线假模型回显也走同一 SSE 链路（5 个增量事件，34 字符）。
- 连续 10 个真实 HTTP 请求停止后上游连接关闭，第 11 个正常任务仍可完成；不靠自然超时回收模型槽位。
- Windows 浏览器分包 POST 曾触发偶发连接重置，已显式恢复 accepted socket 的 blocking 模式并加延迟分包正文回归。
- 静态资源、HTTP JSON API、真实 Agent Loop 回注链路通过。
- 加法 17 + 25 得到 42；任务完成后仍能查看 4 条原始上下文。
- 等待模型的任务不阻塞另一个任务，可单独取消。
- 拒绝跨源、错误 Host、错误内容类型、未知字段、过大 Content-Length 与重复请求头；半发正文不会无限阻塞关闭。
- 本机 Chrome 与 Edge 真实浏览器检查通过：从其他站点链接进入首页、刷新、创建、取消、错误展示、输入草稿与焦点保留、安全文本转义、断线恢复、390px 手机布局无横向溢出；无页面脚本异常。已修复入口页误用 API 同源规则导致 cross_origin 的问题，跨源 API 读写仍受保护。
- [浏览器测试](<../demos/web/tests/web_smoke.cjs>) 与 [运行说明](<Web调试台.md>) 已保存。测试截图位于忽略的本地工具目录。

## 未验证与未实现

- 没有测定冷启动、RSS、千主体常驻占用或端到端模型延迟。
- Unix 分支已在 Linux x86_64 执行全量测试；Windows 结果保留为本机历史记录。
- 已实现真实 OpenAI 兼容调用适配器，但没有拿用户的真实密钥连接外部服务商实测；端到端验证全部使用本机 mock API，不产生外部 API 费用。没有 ASR/TTS 或默认摘要插件。
- 没有整核磁盘恢复、状态迁移、日志轮换、常驻主代理自动重启。
- 进程生命周期清理不等于恶意插件访问沙箱。
- 协作取消不能保证已经发生的外部副作用被撤回。

不能把以上通过结果扩展宣传为生产可用性、安全隔离或长期资源占用保证。
